## Implementation

Tab independently focuses task detail. The renderer counts wrapped rows with ratatui's matching `Paragraph::line_count` API (enabled for the pinned 0.29 dependency). It returns the clamped offset and maximum to the view. The view stores that clamped offset, clamps subsequent movement, and treats a bottom request as transient instead of persisting `usize::MAX`. Confirmation and peek input ownership remain guarded. The encoded numeric range matches the widget's u16 scroll interface; no unbounded-output theorem is claimed.
