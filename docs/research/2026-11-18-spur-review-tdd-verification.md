## Limits and corrected experiments

`semantic_repository_linking: false`. Architecture policy alignment is not
evaluated; current reviewer assignment is unknown; AI review has not run. The app
shows these limits. Full repository C++ linking remains essential for a complete
blast-radius claim.

noncanonical test Deno flag, a strict DuckDB result-draining error and an old Deno
request wait. The same remote build retry passed; the managed fixture and producer
were corrected without weakening guards. A clean first-generation restart then
passed the entire cascade. The old wait's exact root cause is not claimed.

guarded metadata API. Cell mutations used cell versions; profile/SQL selection
used document generation. Rejected version checks did not write. Private cache,
profile and notebook-store namespaces were used with real HOME retained.

No `.spurapp`, deployment, GitHub write or installed-app replacement was performed.
The private candidate remains available for this playground.
