# Bounded macro and function-pointer review

`ortsys` in pinned `vendor/ort/src/lib.rs` maps a bare identifier to an API function pointer; direct calls to the primary table; `.expect` and `?` to status conversion; `nonNull` to panic or error checks; and `@api` direct, result, `?`, and `?; nonNull` to alternate tables. `alternate-api-map.json`, generated by `alternate-api-map.py`, enumerates 56 explicit alternate-table call sites and their mapped row or non-owning effect. It is a lexical list, not a proof of arbitrary macro expansion. The external graph returned `pkg:ort@2.0.0-rc.10::ortsys`; the actual vendored bytes are separately hashed in the manifest.

The bare `GetBuildInfoString` call returns a borrowed informational string (`api_library`). `session/mod.rs` aliases `SessionGetInputCount` and `SessionGetOutputCount` write counts (`sessions`, no owning output); `SessionGetInputName` and `SessionGetOutputName` allocate names that `raw_pointer_to_string` frees through the same allocator (`sessions`, `allocator_default`); `SessionGetInputTypeInfo` and `SessionGetOutputTypeInfo` return type metadata consumed by `ValueType::from_type_info` (`type_info`).

`training/trainer.rs::new_inner` passes eight table fields to `extract_io_names`: TrainingSessionGet{Training,Eval}Model{Input,Output}{Count,Name}. Count calls write scalars; name calls return allocator-backed strings freed in that helper. All eight are within the managed `training` exclusion. `api()` resolves a dynamic `OrtGetApiBase` function pointer, the table/library lifetime belongs to `api_library`. The remaining `extern "system" fn` matches in `alias-search.log` are callbacks supplied to ORT (operator, logger, thread, async and parallel-for), not aliases to named C API methods; their lifetime/behavior is accounted for by `operator_domain`, `kernel_borrows`, `thread_options`, or `async` as applicable.

`define_ep_register!` resolves six named dynamic entry points for ACL, TVM, ArmNN, NNAPI, RKNPU and DML in their respective provider files. Those calls register a provider on session options and return status (`session_options` / `status`); they are not the five provider-option creation APIs classified unreachable by the frozen macOS CPU policy. This finite review does not extend the five unreachable claims to those other providers or to other builds.

`native-creation-search.txt` is a historical, line-number-stale search, including documentation, helper declarations, and non-owning pointer conversions as well as creator leads. The current 89+12 captured leads are represented in `lead-mapping.json` with inherited row explanations and current file hashes. The inherited mapping has not yet received independent per-site semantic validation; it must not be treated as complete acceptance merely because every ID resolves.
